# Galeri fotoğrafları

Kazakistan buluşmaları, etkinlikler ve saha fotoğraflarını **bu klasöre** koyun.

- Desteklenen formatlar: `.jpg`, `.jpeg`, `.png`, `.webp`
- Buraya eklediğiniz **her görsel otomatik olarak** ana sayfadaki "Sahadan" slaytında görünür — kod değiştirmeye gerek yok.
- Sıralama dosya adına göredir; istediğiniz sırayı vermek için `01-...`, `02-...` gibi adlandırın.
- İdeal en-boy: yatay (ör. 1600×1000). Çok büyük dosyaları (>2MB) önceden sıkıştırın.
- Açıklama/altyazı eklemek isterseniz dosya adını şöyle verin: `01-almaty-ogrenci-bulusmasi.jpg`
  → slaytta "Almaty Ogrenci Bulusmasi" başlığı görünür.

> Bu klasör boşken site bozulmaz; zarif bir yer-tutucu gösterilir.
