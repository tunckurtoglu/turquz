# Hero (üst bölüm) arka plan görseli

Ana sayfanın en üstündeki büyük arka plan görselini **bu klasöre** koyun.

- Tek bir görsel yeterli: `.jpg`, `.png` veya `.webp`
- Buraya attığınız görsel **otomatik olarak** hero arka planı olur (kod değiştirmeye gerek yok).
- Önerilen: geniş, yatay, yüksek çözünürlük (en az 1920×1080). Dünya haritası + İstanbul silueti gibi.
- Görsel koyulmazsa hero, marka renklerinde (lacivert + altın) zarif bir gradient gösterir; site bozulmaz.
- Birden çok dosya varsa dosya adına göre **ilki** kullanılır (örn. `hero.jpg`).

> Metin okunaklı kalsın diye görselin üstüne otomatik koyu degrade bindirilir.
